## Project

A minimal one-page personal website (leowla.com) built with Astro and Tailwind CSS, deployed to Cloudflare Workers. Started from the Cloudflare Workers Astro blog starter template and stripped down to a single static landing page.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Astro dev server at `localhost:4321` |
| `npm run build` | Build static output to `./dist/` |
| `npm run preview` | Build, then run `wrangler dev` against the Workers entrypoint |
| `npm run check` | Full pre-flight: `astro check && astro build && tsc && wrangler deploy --dry-run` |
| `npm run deploy` | `wrangler deploy` (assumes `dist/` is already built — use `npm run build && npm run deploy`) |
| `npm run cf-typegen` | Regenerate `worker-configuration.d.ts` from `wrangler.json` |
| `npm run format` / `npm run lint` | Biome format/lint with autofix (`:check` variants are non-mutating) |

Node >=22 is required.

## Architecture notes

- **Astro + Cloudflare Workers adapter.** `astro.config.mjs` sets `adapter: cloudflare({})`, and `wrangler.json` points `main` at `@astrojs/cloudflare/entrypoints/server` with `./dist` mounted as the `ASSETS` binding. The build produces both static assets and a Worker entry; `wrangler deploy` ships them together. Custom domains `leowla.com` and `www.leowla.com` are declared in `wrangler.json`.
- **Content lives in `src/pages/index.astro`.** Site title/description come from `src/consts.ts`. There are no collections, no blog, no MDX — adding pages means dropping `.astro` files in `src/pages/`.
- **Fonts are self-hosted via Astro's font API.** `Monaspace Radon` is loaded as a local variable woff2 from `src/assets/fonts/` and exposed as the `--font-monaspace-radon` CSS variable. `BaseHead.astro` emits the `<Font>` tag; reference the variable in Tailwind via `font-monaspace-radon`.
- **Tailwind v4 via Vite plugin** (`@tailwindcss/vite`), no `tailwind.config.js`. Global styles live in `src/styles/global.css`, imported once from `BaseHead.astro` so every page that uses that component picks them up.
- **Biome handles both formatting and linting.** `useSortedClasses` is enforced (Tailwind class ordering is auto-fixed). For `.astro/.svelte/.vue` files, `useConst`, `useImportType`, `noUnusedVariables`, and `noUnusedImports` are disabled to avoid false positives from frontmatter scripts. `dist`, `.astro`, `.wrangler`, and the generated `worker-configuration.d.ts` are excluded.

## Things to know

- `worker-configuration.d.ts` is generated by `wrangler types` — do not hand-edit. Re-run `npm run cf-typegen` if you change `wrangler.json` bindings.
- `npm run preview` ≠ `astro preview`. It builds and runs the actual Worker via `wrangler dev`, which is what you want to validate Cloudflare-specific behavior.
